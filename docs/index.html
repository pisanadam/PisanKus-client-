Sık sorulanlar

Minecraft hesabım olmadan kullanabilir miyim?

Hayır. Opbay Client yalnızca resmî Microsoft oturum akışını destekler ve oyunu başlatmadan önce hesabın Minecraft: Java Edition lisansını doğrular. Korsan ("cracked") giriş desteklenmez.

CurseForge içerikleri neden görünmüyor?

CurseForge üçüncü taraf uygulamalar için API anahtarı zorunlu tutuyor. Ayarlar → İçerik bölümünden console.curseforge.com üzerinden aldığın ücretsiz anahtarı girdiğinde arama açılır. Modrinth için anahtar gerekmez.

Java kurmam gerekiyor mu?

Gerekmiyor. Launcher sistemdeki Java sürümlerini tarar; oyunun ihtiyaç duyduğu sürüm yoksa uygun Eclipse Temurin çalışma zamanını kendisi indirir.

Mevcut dünyalarımı taşıyabilir miyim?

Evet. Profil sayfasındaki Dünyalar sekmesinden bir .zip arşivini içe aktarabilir ya da profil klasörünü açıp saves dizinine doğrudan kopyalayabilirsin.

Android sürümünde oyun neden hemen başlamıyor?

Android'in kendi çalışma zamanı Minecraft Java Edition'ı çalıştıramaz; ayrı bir Java çalışma zamanı (JRE) gerekir. APK bir JRE ile birlikte gelmez — uygulamayı kurduktan sonra Ayarlar → Java çalışma zamanı bölümünden cihazınıza uygun bir arşivi (.tar.xz, .tar.gz veya .zip) içe aktarın. Çalışma zamanı kurulu değilse başlatma denemesi ne yapmanız gerektiğini anlatan bir mesajla durur.

Android'de hangi Minecraft sürümleri var?

Mojang'ın yayımladığı tüm kanallar: sürümler, anlık görüntüler ve 2010 dönemine ait beta (örn. b1.7.3) ile alfa (örn. a1.2.6) yapıları. Profil oluştururken kanal filtreleriyle seçebilirsiniz.

Verilerim nerede saklanıyor?

Tüm profiller, oturum bilgileri ve indirilen dosyalar yalnızca kendi bilgisayarında tutulur. Opbay Client'ın herhangi bir sunucusu ya da telemetrisi yoktur.

Windows "bilinmeyen yayıncı" uyarısı veriyor.

Paketler kod imzalama sertifikasıyla imzalanmadığı için SmartScreen uyarı gösterir. "Ek bilgi" → "Yine de çalıştır" ile devam edebilirsin. Dilersen kaynak koddan kendin derleyebilirsin.

macOS "uygulama zarar verebilir" diyor / açılmıyor.

Paketler Apple tarafından noter onayından (notarization) geçirilmediği için Gatekeeper engeller. Uygulamayı Programlar klasörüne taşıdıktan sonra Terminal'de xattr -dr com.apple.quarantine "/Applications/Opbay Client.app" komutunu çalıştır ya da uygulamaya sağ tıklayıp "Aç" seçeneğini kullan.

İndirdiğim sürüm ne kadar güncel?

Paketler her kod güncellemesinde otomatik derlenir ve buradaki bağlantılar her zaman en son yapıyı indirir. Bağlantı adresleri sabittir, sürüm numarası içermez.
